# Консольная Игра: Target Hunter 🎯

Простая консольная игра на языке C, где игрок должен находить и поражать цели, набирая очки за ограниченное время.

## 🎮 Описание игры

Игрок управляет символом `@`, перемещаясь по полю размером 50x20. Цель игры — найти цель `O` и нажать `F`, чтобы "поразить" её. За каждую поражённую цель начисляется 1 очко. Игра длится 60 секунд.

## ✨ Особенности

- Система регистрации и входа пользователей
- Хранение рекордов в файле
- Таймер игры (60 секунд)
- Цветной вывод в консоли (ANSI-коды)
- Простое управление (WASD)

## 🛠️ Требования

- Компилятор C (GCC, Clang)
- Библиотека **ncurses** (для Linux/Mac)
- Для Windows можно использовать PDCurses или альтернативы

## 📦 Установка и запуск

### Linux / macOS

1. Установите ncurses (если не установлена):
   ```bash
   # Ubuntu/Debian
   sudo apt-get install libncurses5-dev libncursesw5-dev
   
   # macOS
   brew install ncurses

2. Клонируйте или скачайте файлы:

   game.c
   game.h
   main.c 


3. Скомпилируйте:

   gcc -o game main.c game.c -lncurses

4. Запустите:

   ./game

Windows (с MinGW)
Установите PDCurses или используйте альтернативу

Компиляция может потребовать адаптации кода (замена ncurses.h)

🏗️ Структура проекта

.
├── main.c          # Основной цикл программы, меню
├── game.h          # Заголовочный файл с объявлениями
├── game.c          # Логика игры, рендеринг, таймер

🔧 Функции
